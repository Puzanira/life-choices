# Design Contract — life-choices («Спасибо, не надо»)

Назначает **эталон** для дизайн-гейта проекта. Механизм гейта — общий, студийный,
НЕ дублируется здесь: `system/policies/DESIGN_REVIEW_POLICY.md` (3 слоя + Design
Checklist из 7 пунктов), бриф зрячего скептика —
`system/templates/increments/DESIGN_SKEPTIC_BRIEF_TEMPLATE.md`, место во флоу —
`INCREMENT_MODEL_SPEC.md §3` + `INCREMENT_TEMPLATE.md §5`.

Этот файл — недостающий винтик: у проекта нет помакетных PNG на каждый экран,
поэтому эталон надо назвать явно, иначе слою «сверка с макетом» не к чему
привязаться.

## Правило применения

- **КАЖДЫЙ визуальный инкремент** (сцены / UI / спрайты / раскладка / камера /
  композиция) прогоняет `DESIGN_REVIEW_POLICY.md` — 3 слоя, ДО плейтеста
  основательницы, параллельно код-скептику Codex:
  - **Слой 1** — в done-contract (§2) добавить критерии из эталона: какие элементы
    есть, где стоят, какого размера относительно кадра; инвариант «на экране нет
    ничего, чего нет в эталоне» (артефакты / неоскиненные плашки / плейсхолдеры /
    наложения-перекрытия / вылет текста за плашку = провал).
  - **Слой 2** — гардируемые инварианты как тесты по ОТРИСОВАННОМУ результату
    (не `activeSelf`/контейнер): floor на отрисованный размер; позиция/отношения;
    «целиком в кадре»; **исчерпывающее перечисление активных видимых Image/renderer
    (лишний элемент = провал)**; спрайт не null/не плейсхолдер; **элементы не
    перекрывают друг друга (баннер не наезжает на карту)**.
  - **Слой 3** — свежий **зрячий Claude-субагент** (не владелец) получает эталон +
    ПОЛНЫЙ набор скринов (каждое состояние, не «удачный кадр») + Design Checklist →
    вердикт «пропустить / вернуть (пофреймовый список)». Плюс **Maintainer сам
    смотрит тот же набор против эталона**. Оба зелёные → плейтест.
- **Логический инкремент** (баланс, контент-теги, механика без визуала) — явно
  помечает §5: **`design-skeptic: n/a (без визуала)`**.

## Известные пробои (что гейт ловит — почему он тут)

- home-alone: ваза висела над комодом, чёрная неоскиненная плашка, гипер-мелкие
  флаконы — дошли до плейтеста, т.к. код-скептик судит числа, а не картинку.
- **life-choices, 2026-07-19 (кризис-блиц):** пустой баннер-рубрика наехал на
  карточку и закрыл текст мысли; «ВСЁ НОРМАЛЬНО» не влезла в плашку размера «ДА»
  (текст разъехался). Код-гейт + Codex-скептик зелёные, human-eye ночью не было →
  баг у основательницы. Именно этот класс закрывает зрячий дизайн-скептик +
  личный просмотр скринов Maintainer'ом.

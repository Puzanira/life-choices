## Процесс
1. Пройди опись с основательницей группа за группой (приоритет: ответы/купол →
   тревоги/салют → телефон → кризис/депрессия → эмбиент). На каждое событие —
   1–3 кандидата: дай послушать (пути к скачанным файлам), она выбирает.
2. Лицензии: CC0 приоритетно, CC-BY допустимо (атрибуция в манифест). Источники:
   freesound.org, kenney.nl, sonniss GDC packs, pixabay. НИКАКИХ «сомнительных» рипов.
3. Складывай: `docs/assets/audio-picks/<группа>/<событие>--<вариант>.(wav|ogg)`.
4. Веди `docs/assets/audio-picks/manifest.md`: событие из описи → выбранный файл →
   источник-URL → лицензия → статус (кандидат/УТВЕРЖДЁН основательницей).
5. Главный художественный приём (из описи, согласуй первым): в депрессии весь микс
   уходит «в вату» (лоу-пасс/глушение) и возвращается по ступеням попаданий.
6. Финал сессии: манифест с утверждёнными звуками → скажи основательнице передать
   Maintainer-сессии на инкремент внедрения.

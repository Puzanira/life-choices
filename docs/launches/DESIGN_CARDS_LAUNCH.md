   длительные эффекты, блокировка по цене (BLOCK$ + «цена N ₽»).

## Процесс
1. Пройди с основательницей отрезок за отрезком (таблица уже сгруппирована:
   детство → школа → … → поздняя жизнь). На каждом отрезке: (а) закрыть дыры
   существующих карточек (Δ, реплики, некролог — предлагай варианты в тоне);
   (б) предложить НОВЫЕ карточки, если отрезок жидкий (в таблице видно плотность);
   (в) сверить экономику отрезка (сколько ₽ приходит/уходит, доступность BLOCK$).
2. Результат веди в `cards-script-<отрезок>.md` строго в формате колонок CSV
   (чтобы посадка была механической): ID, Карточка, Когда, Тип, ДА-механика,
   ДА-Δ, НЕТ-механика, НЕТ-Δ, Ведущий(ДА/НЕТ), Некролог(ДА/НЕТ), Флаги,
   Длительный эффект, Тон. Помечай каждую строку: НОВАЯ / ПРАВКА <ID> / БЕЗ ИЗМЕНЕНИЙ.
3. Жёсткие рамки (не нарушать без явного слова основательницы):
   - канон-возрасты вех (работа 18, отношения 20, энергия 25, здоровье 30,
     свадьба/ребёнок, кризис ~45) не двигаются;
   - пейсинг: механики не открываются подряд, ≥~10 обычных выборов между вехами;
   - «начать встречаться» — ДО открытия шкалы отношений (правится в реализации);
   - некролог: законченные предложения в прошедшем времени, лимит ~15 строк сборки.
4. Утверждённые основательницей пачки помечай «✅ УТВЕРЖДЕНО <дата>» — по ним
   основательница скажет Maintainer-сессии «сажай в CSV» (та посадит с прогоном
   пейсинг/баланс-тестов).

# Шрифты — «Спасибо, не надо»

Ответ на `docs/design-tasks/2026-07-18-p0-assets-and-csv.md` (Задача 1, шрифт).
Оба — свободная лицензия **SIL Open Font License 1.1** (OFL), кириллица есть.

**Актуальный выбор (утв. 2026-07-29, см.
`docs/design-tasks/2026-07-29-meeting-revisions-spec.md` §8):**
- **Заголовки / основные надписи → `Arimo Bold`** (свободный аналог Helvetica,
  метрически совместим).
- **Комментарии → `Rubik`**.

| Файл | Шрифт | Начертания | ₽ | Роль |
|------|-------|-----------|----|--------------|
| `Arimo-Bold.ttf` | Arimo Bold | Bold | ✅ | **заголовки/надписи** — аналог Helvetica Bold, полная кириллица + ₽ (OFL 1.1) |
| `Arimo-Regular.ttf` | Arimo | Regular | ✅ | доборный вес Arimo при необходимости |
| `Rubik-VariableWght.ttf` | Rubik | вариативный, ось веса 300–900 (есть Black) | ✅ | **комментарии** — геометрия под стиль, кириллица + ₽ |
| `Rubik-Bold-wght700.ttf` | Rubik Bold | статический инстанс wght=700, нарезан из файла выше | ✅ | **реплики Ведущего** — legacy uGUI растрирует ДЕФОЛТНЫЙ инстанс вариативного файла (300, Light), поэтому жирное начертание нужно отдельным файлом (в проекте: `Art/Resources/Fonts/Rubik-Bold.ttf`) |
| `RussoOne-Regular.ttf` | Russo One | один тяжёлый вес | ❌ (нет ₽) | запасной блочный «ТВ-шный» |

Лицензии: `Arimo-LICENSE.txt` (SIL OFL 1.1), `Rubik-OFL.txt`, `RussoOne-OFL.txt`.
Все — свободные для встраивания в билд.

**В Unity/TMP:** Rubik — вариативный; для дисплейных заголовков брать вес
**~900 (Black)**. Если пайплайн не любит вариативные — инстансировать Black
статикой. Для пилюли денег нужен знак ₽ → берём Rubik (у Russo One его нет,
пришлось бы рисовать отдельно).

Обводка/тень букв (как в мокапах) — эффектами TMP (Outline + Underlay), не
запекать в шрифт.

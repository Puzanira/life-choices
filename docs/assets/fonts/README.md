# Шрифты — «Спасибо, не надо»

Ответ на `docs/design-tasks/2026-07-18-p0-assets-and-csv.md` (Задача 1, шрифт).
Оба — свободная лицензия **SIL Open Font License 1.1** (OFL), кириллица есть.

| Файл | Шрифт | Начертания | ₽ | Рекомендация |
|------|-------|-----------|----|--------------|
| `Rubik-VariableWght.ttf` | Rubik | вариативный, ось веса 300–900 (есть Black) | ✅ | **основной** — геометрия под стиль, кириллица + ₽ |
| `RussoOne-Regular.ttf` | Russo One | один тяжёлый вес | ❌ (нет ₽) | альтернатива — блочный «ТВ-шный», если хочется жёстче |

Лицензии: `Rubik-OFL.txt`, `RussoOne-OFL.txt`.

**В Unity/TMP:** Rubik — вариативный; для дисплейных заголовков брать вес
**~900 (Black)**. Если пайплайн не любит вариативные — инстансировать Black
статикой. Для пилюли денег нужен знак ₽ → берём Rubik (у Russo One его нет,
пришлось бы рисовать отдельно).

Обводка/тень букв (как в мокапах) — эффектами TMP (Outline + Underlay), не
запекать в шрифт.

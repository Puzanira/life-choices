# World / Vibe / Art Direction — «Спасибо, не надо»

Статус: **визуальный стиль решён** (2026-07-17, пивот). Детали ассетов —
`docs/new_concept/assets.md`; стайлфрейм — `docs/assets/style/styleframe-03.png`.

## Vibe

Приторно-бодрая телевикторина 70–80-х как обёртка над стылым арт-ядром про то,
что «нельзя успеть всё». Громко, ярко, конфетти — и тем сильнее контраст, когда
жизнь проседает и шоу само тускнеет.

## Тон юмора

- Ведущий — **Цезарь Фликерман из «Голодных игр»**: восторженный, чуть
  глумливый, на публику. Реплики короткие (1–3 слова), не на каждый выбор.
- Абсурд + сатира на «успешный успех»; **чёрный юмор дозирован**, без драмы и
  морализаторства.
- Юмор — из конкретики: реплики Ведущего и некролог цитируют твои решения.

## Visual Direction ✅

Язык американских телевикторин 70–80-х: взрывной **санбёрст** (лучи), звёзды,
чанки-бейджи с толстым чёрным контуром и 3D-буквами, чистые цвета (кобальт,
жёлтый, красный, оранжевый, белый). Сигнатурный элемент — плашки ответа
**«ДА» (зелёная) / «СПАСИБО, НЕ НАДО» (красная)**, одинаковый крупный шрифт.
Экран **16:9**.

**Состояние «Депрессия»** — та же графика, обесцвеченная в жёсткое ч/б с одним
акцентом, зерно, тишина/искажённый звук.

**Реакция шоу на состояние** (глобальный отклик, не эффект карточки): шкалы в
порядке → сияет, конфетти; здоровье/отношения/энергия проседают → тускнеет.

Шрифт: жирный дисплейный санс с кириллицей (кандидаты Bebas Neue / Anton /
Fredoka / Shrikhand — проверить кириллицу). Ассеты генерились через Higgsfield
(`nano_banana_pro`, 16:9), `styleframe-03.png` — reference-input для
консистентности.

## Audio Direction

Джингл-опенер, фанфары на рубрики, фоновая петля + её искажённая «депрессивная»
версия, клики ответов. (Спека — `assets.md`; вне первого играбельного среза.)

## World

Узнаваемая современность как поле сатиры (работа, ипотека, кризис среднего
возраста, инфоцыгане, ЗОЖ-секты), поданная через рубрики телешоу
(ПОРА ЗАРАБАТЫВАТЬ! · ПЕРВАЯ ЛЮБОВЬ! · КРИЗИС СРЕДНЕГО ВОЗРАСТА!).

## Characters

- **Игрок — безымянный «каждый из нас»**, проживающий жизнь этапами
  (детство → старость). Жизнь выдаётся, игрок реагирует.
- **Ведущий** — невидимый голос/облачки шоу, комментирует и объявляет рубрики.
- Мутные персонажи из карточек (коуч, инфоцыган, «за тобой пришли» и т.п.) —
  флейвор ситуаций-выборов.

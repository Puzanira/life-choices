### 3.1 Первое расставание — карточка, которой не было

Раньше отношения можно было потерять только руками, не удержав шкалу. Теперь
расставание бывает и **выбором** — и это первый раз, когда шкала гаснет по твоему «да».

| Колонка | Значение |
|---|---|
| ID | `FB31` · **НОВАЯ** |
| Карточка | **Он говорит, что ему нужно побыть одному. Отпустить?** |
| Когда | 20–24, если шкала отношений открыта |
| Тип | Развилка |
| ДА — механика | **Разрыв: партнёр уходит, шкала гаснет** |
| ДА — Δ | `BREAK:Отн` |
| НЕТ — механика | Удержал — но отношения проваливаются в красную зону и начинают отсчёт |
| НЕТ — Δ | Отн →38 % |
| Ведущий (ДА) | «Отпустил!» |
| Ведущий (НЕТ) | «Держится!» |
| Некролог ДА | Первого человека отпустили, когда он попросил. |
| Некролог НЕТ | Первого человека удержали силой, и вышло только хуже. |
| Флаги | `ZONE` |
| Тон | `risky` |

`Отн →38 %` на отказе — не просто минус, а вход в красную зону: ниже 40 % дольше
десяти секунд шкала рвётся сама. Удержал — теперь держи руками.

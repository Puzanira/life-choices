### 2.1 Что важно про боксы

- **Центры в спеке почти везде верные, размеры — нет.** Отношения (`674,101` vs
  `675,102`) и Здоровье (`1294,102` vs `1293,102`) совпадают до 1 px, а ширины/высоты
  разъезжаются на 22–24 px. Значит спек снимался по центрам, а габариты прикидывались.
  **Ставить по измеренным `(x,y,w,h)`, а не досчитывать от центра.**
- **Банка**: спековский бокс `1700,10,175,235` — это **банка вместе с монетой**
  (измерено `1664,8,173,242`), и он смещён по X на 36 px. Для HUD нужны два
  отдельных объекта: банка `1674,74,161,174` и монета `1714,6,68,68`.
- **Карточка**: верх бокса — не корпус плашки, а **чёрный контур верхнего
  «язычка»** на `y=229` (сам корпус начинается с `y≈270`). Спековские `250` —
  промах между этими двумя краями.
- **Кнопки** заметно крупнее и повёрнуты сильнее, чем в спеке; см. §4.

### 4.2 Звонок ребёнка (эталон `Экран звонит телефон.png`)

| Замер | Значение |
|-------|----------|
| Корпус трубки (связная компонента) | `14, 351, 258, 384` |
| Красные дуги (сами по себе, отдельные компоненты) | `0, 313, 330, 390` |
| Объединение «трубка + дуги» | **`0, 313, 330, 422`** |
| Спек §4-E говорит | `20, 330, 240, 400`, rot ≈ −14° |

Дуги **не примыкают** к корпусу (это отдельные штрихи) — CCL их разделяет, и
на эталоне они уходят за левый край экрана (`x=0`). Точный угол наклона
надёжно не решается автоматикой (силуэт «C» + обрез краем): подгонка даёт
диапазон **−15…−25° (против часовой)** с IoU 0.25, что для приёмки мало.
**Ставить накладыванием на PNG вручную** — стартовые значения: `scale ≈ 0.53`,
`rot ≈ −20°`, AABB стремить к `0, 313, 330, 422`.

| Размер файла | 1536 × 1024, RGB, **без альфы** |
| Центр схождения лучей | `768, 512` — совпадает с геометрическим центром (яркостной центроид `787, 534`, отклонение 19/22 px) |
| Число лучей | **20–21** (устойчиво на радиусах 300 и 450) |
| Радиус жёлтого ядра (R−B > 30) | **192 px** (p99 = 183) |
| Радиус почти-белого ядра (min канал > 200) | **236 px** |
| Диагональ экрана 1920×1080 | **2202.9 px** |
| **Нужный равномерный масштаб** (вписанный круг спрайта ≥ диагональ) | **×2.151** → RectTransform **3305 × 2203** |
| Если бы хватило покрытия только по ширине | ×1.434 — **недостаточно** при вращении |

Логика: при вращении вокруг центра экрана спрайт обязан содержать круг диаметром
= диагональ экрана. Круг, вписанный в спрайт, ограничен **меньшей** стороной (1024),
отсюда 2202.9 / 1024 = 2.151.

⚠ **Два следствия, требующие решения:**
1. **Апскейл ×2.15.** Лучи — гладкие градиенты, апскейл почти незаметен, но
   текстура импортируется 1536×1024 и растягивается. Альтернатива — рисовать
   лучи шейдером процедурно (тогда ни апскейла, ни оверскана).
2. **Жёлто-белое ядро вылезет.** При ×2.151 радиус жёлтого ядра на экране =
   192 × 2.151 ≈ **413 px**, почти-белого ≈ **508 px**. Карточка-вопрос
   (`413,229,1093,721`) закрывает центр только начиная с `y = 229`, то есть
   на 311 px от центра. Значит жёлтое проступит полосой примерно
   **x 777…1143, y 150…229** (над карточкой, под барами) и симметрично снизу.
   На эталоне `Экран спокойный обычный.png` в этой зоне **жёлтого нет** —
   пиксель `(960, 170)` = `(119, 167, 243)`, чистый голубой. То есть эталон
   собирался с меньшим масштабом фона (ядро было спрятано за карточкой).
   Нужно решение: приглушить/убрать ядро, либо принять его как есть.

## 12. Решения основательницы по вердикту дизайн-скептика (2026-07-29)

1. **Маркеры = сами арт-элементы** («сердце и есть маркер, человечек тоже и есть
   маркер»): у отношений по дорожке ездит НАРИСОВАННОЕ СЕРДЦЕ (выпатчить из
   центра дорожки, вырезать спрайтом, вести по значению через маппинг §11-2);
   у здоровья маркер — исходный чёрный ЧЕЛОВЕЧЕК-силуэт (~47 px, вырезать из
   оригинального спрайта ДО патча §11-3, вести по маппингу §11-4). Никаких
   code-drawn фигурок. Концевые декоры (лица, череп, сердце-эндпоинт здоровья)
   остаются на местах.
2. **Палитра: арт-пак = канон.** Эталоны — истина РАСКЛАДКИ, не цвета (собраны из
   ранних версий спрайтов). Зелёные/красные дорожек, синий рамки, волосы — как в
   спрайтах; тесты цветов равняются на спрайты.
3. **Молния батареи — отдельным слоем**: выпатчить из заливки, рисовать поверх
   всегда целиком, контрастной на любом фоне.
4. **Цвет текста: INK #0B0F1A** из токенов (не чисто-чёрный эталонов).

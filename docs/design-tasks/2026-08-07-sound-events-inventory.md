# Опись звуковых событий — для дизайн-сессии «Звук»

> Сгенерировано Maintainer-сессией 2026-08-07 из фактического кода игры.
> Это ПОЛНЫЙ перечень взаимодействий/анимаций/состояний, под которые подбираются
> звуки. Сейчас в игре звука НЕТ вообще — чистый лист.
> Тон игры: приторно-бодрое ТВ-шоу (Цезарь Фликерман), дудл-арт; звук должен
> усиливать контраст «весёлая обёртка ↔ жизнь как она есть».

## 1. Сквозные / всегда

| Событие | Где/триггер | Характер (подсказка, не догма) |
|---|---|---|
| Эмбиент шоу | фон всех игровых экранов (лучи вращаются) | лёгкий студийный гул/публика, ненавязчивый луп |
| Музыка-тема | опенер и/или геймплей | бодрая шоу-тема; в депрессии глохнет/искажается |

## 2. Карточки и ответы

| Событие | Где/триггер | Характер |
|---|---|---|
| Раздача карточки | новая карточка въезжает (анимация входа 0.24 с) | вжух/шелест карты |
| Ответ ДА | панч зелёной плашки (только принятый ответ) | позитивный «дзынь»/штамп |
| Ответ НЕТ | панч красной плашки | суховатый штамп/отказ |
| Таймаут («молчание») | купол дожёг, ответ монеткой | тикающий провал + смешок зала? |
| Купол: последняя секунда | весь купол мигает красным (пульс 0.35 с) | учащающийся тик/сердцебиение |
| BLOCK$ (нет денег) | серая карточка + баннер «Как жаль…» + чип цены | грустный тромбон «вомп-вомп» (канон шоу) |

## 3. Деньги (крутилка)

| Событие | Где/триггер | Характер |
|---|---|---|
| Принятый тик крутилки | каждый тик (кэп ~5/с) | механический щелчок динамо |
| Монета падает в банку | доход-тик, монета ныряет в горловину | «дзынь» монетки (вариации по высоте) |
| Тревога денег | банка+монета краснеют на BLOCK$ (пульс 0.7 с) | тревожный минорный акцент, короткий |

## 4. Энергия (датчик — «зажми и держи»)

| Событие | Где/триггер | Характер |
|---|---|---|
| Начало удержания | датчик поднят, батарея начала расти (16%/с) | нарастающий «вдоооох»/заряд |
| Удержание (луп) | пока растёт | мягкий луп зарядки, питч вверх с уровнем |
| Отпустил | рост встал | короткий выдох |
| Тревога энергии | батарея < 20%, красная + пульс | того же семейства, что тревога денег |
| ВЫГОРАНИЕ: вход | полноэкранный перехват | резкий провал/глушение всего микса |
| ВЫГОРАНИЕ: удержание-выход | держит датчик, приходит в себя (~2 с) | обратный подъём, «продышался» |

## 5. Отношения (джойстик-балансир)

| Событие | Где/триггер | Характер |
|---|---|---|
| Маркер вошёл в зелёную зону | пересечение границы 40/75 | мягкий позитивный «блип» |
| Маркер вышел из зоны | тревога: красный кант + пульс | тревожный «блип» ниже |
| РАССТАВАНИЕ | плашка «РАССТАЛИСЬ», балансир закрылся | разбитое сердце: стеклянный треск + «ооох» зала |
| Второй шанс | шкала открылась заново (веха) | тёплый перезапуск |

## 6. Здоровье

| Событие | Где/триггер | Характер |
|---|---|---|
| Открытие (30) — «здоровье тает» | входной экран-туториал | глухой колокол/тик часов |
| Тревога здоровья | < 20%, красный кант + пульс | семейство тревог |
| Лечение выбором | карточка с плюсом к здоровью применена | целебный «глоу» |

## 7. Ребёнок (телефон)

| Событие | Где/триггер | Характер |
|---|---|---|
| Звонок: выезд трубки | трубка выезжает, дрожит (окно 5 с) | детский рингтон, настойчивый |
| Поднял («!») | успокоение + уезд + салют | тёплое «алло»-мурлыканье + звёзды |
| Проспал | «поникшая» трубка уезжает + реплика Ведущего | оборванный гудок, тишина-провал |
| «Плохой родитель» (2-й пропуск) | флаг включился | низкий финальный акцент (редкий, страшный) |

## 8. Салют и награды

| Событие | Где/триггер | Характер |
|---|---|---|
| StarBurst | 4–5 звёзд из центра (туториал пройден / шкала починена / звонок поднят) | праздничный свисто-хлопок конфетти |

## 9. Туториалы (D-экраны и входы спецрежимов)

| Событие | Где/триггер | Характер |
|---|---|---|
| Экран открылся | затемнение + крупная шкала + окна | шоу-фанфара «внимание, новая рубрика!» |
| Условие выполнено | фейд + салют + снятие паузы | та же фанфара-разрешение |
| Реплика Ведущего (облачко) | поп-ин облачка (~30–40% выборов) | «бла-бла»-мурлыканье рупора/короткий гонг по тону (positive/risky/absurd/cautious/fatal/skip — 6 тонов в пуле) |

## 10. Кризис (блиц/импульс) и депрессия

| Событие | Где/триггер | Характер |
|---|---|---|
| Блиц: старт | входной экран «КРИЗИС! БЛИЦ!» | драматическая перебивка, ускоренный пульс шоу |
| Блиц: мысль появилась | каждая из 5 мыслей (по 5 с) | вжик-карточка + нервный тик |
| Блиц: попал «ВСЁ НОРМАЛЬНО» | успех мысли | короткий позитив |
| Блиц: провал / «О НЕТ» / таймаут | +1 провал (счётчик) | резкий минус |
| Импульс (INVERT) | «молчание = ДА», надо успеть нажать НЕ НАДО | сирена-предупреждение, тикающая бомба |
| Депрессия: вход | ч/б + зерно, всё глохнет | ГЛАВНЫЙ приём: весь микс уходит в вату/лоу-пасс |
| Депрессия: пульс | тусклая вспышка раз в ~1.5 с (окно 0.75 с) | одинокий глухой удар сердца |
| Депрессия: попадание | +ступень цвета (5 всего) | с каждым попаданием микс/цвет возвращаются на ступень |
| Депрессия: промах/замок | анти-заколачивание (локаут 1 с) | ватный «пшик», ничего не происходит |
| Депрессия: выход | цвет вернулся | звук «мир снова включили» |

## 11. Рамка жизни

| Событие | Где/триггер | Характер |
|---|---|---|
| Опенер: старт («НАЧАТЬ ЖИЗНЬ») | зелёная кнопка | гонг начала шоу + аплодисменты |
| Вехи возраста | бейдж меняет цифру (возраст догоняет карточку) | лёгкий флип цифр |
| ФИНАЛ «ИТОГИ ШОУ» | кулисы, некролог | финальная тема: аплодисменты + грусть-ирония по типу конца (старость/выгорание/FATAL-дичь) |
| «НАЧАТЬ ЗАНОВО» | зелёная на финале | перемотка/реванш |

## Приоритет внедрения (предложение)
1) Ответы/раздача/купол (каждые 6–10 с игры) → 2) тревоги+салют → 3) телефон →
4) кризис/депрессия (главный художественный приём — глушение микса) → 5) эмбиент/темы.

## Технические рамки для подбора
- Лицензии: CC0/CC-BY (с атрибуцией в файле-манифесте) — как со шрифтами (OFL-прецедент).
- Формат: WAV/OGG, короткие ≤2 с для событий, лупы — бесшовные.
- Складывать: docs/assets/audio-picks/<категория>/ + manifest.md (источник, лицензия, событие из этой описи).
- В код НЕ вшивать — внедрение звука делает Maintainer-сессия отдельным инкрементом по готовому манифесту.

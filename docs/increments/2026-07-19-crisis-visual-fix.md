## 1. Пересказ дизайна

**Чиню сломанную композицию кризис-блица** (баг с плейтеста основательницы,
2026-07-19): пустой баннер-рубрика наехал на карточку и закрыл текст мысли;
«ВСЁ НОРМАЛЬНО» не влезла в плашку размера «ДА» — текст разъехался.

- **Баннер-рубрика больше не перекрывает карту.** По мокапу S4 баннер — это
  краткое ОБЪЯВЛЕНИЕ, а не полоса поверх карты. Делаем его **коротким
  блокирующим битом** (~1.5с, без ввода, авто-снятие): игра на паузе, баннер
  показывает свой ТЕКСТ по центру, затем снимается — и ТОЛЬКО ПОСЛЕ появляется
  карта/блиц. Пустого баннера над картой быть не может. (Заодно закрывает
  открытый вопрос «баннер не морозит таймер» — теперь морозит на свой бит.)
- **Кризис-плашки «ВСЁ НОРМАЛЬНО» / «О НЕТ» получают свой размер/шрифт.** Плашки
  подгоняются под ДЛИННУЮ подпись (перенос/автофит), текст целиком внутри, не
  вылезает и не режется. По S6: две читаемые кнопки, зелёная/красная, на местах
  плашек ответа, «ВСЁ НОРМАЛЬНО» рандомит сторону. Импульс (S13) — «СПАСИБО, НЕ
  НАДО» тоже влезает.
- Механика кризиса НЕ меняется (блиц/импульс/провалы — как есть); только
  композиция/раскладка.

> Вне scope: остальная механика; звук. Числа таймингов — как есть.

## 2. Done contract

Дизайн-критерии (Слой 1) выведены из эталона `docs/screens/index.html` S4/S6/S13.

| # | Class | Criterion |
|---|-------|-----------|
| 1 | boots | Игра стартует без ошибок. |
| 2 | player path | Кризис в 45: сначала баннер-бит «КРИЗИС… БЛИЦ!» (пауза, текст виден, ~1.5с), ПОТОМ блиц — карта мысли и две кнопки; управление ←/→ как было. |
| 3 | interaction path | Механика блица/импульса без регрессий (5×2с, рандом-сторона, ≥2 провала→импульс, INVERT). |
| 4 | failure/restart path | Как было; баннер-бит не софтлочит (авто-снятие без ввода); рестарт чист. |
| 5 | observability | Изменение видно (баннер→карта, кнопки читаемы). |
| 6 | **design — раскладка по S4/S6/S13** | **(a)** баннер-рубрика НЕ пересекается с картой ни в одном кадре (карта скрыта, пока баннер, и наоборот); **(b)** текст «ВСЁ НОРМАЛЬНО»/«О НЕТ»/«СПАСИБО, НЕ НАДО» ЦЕЛИКОМ внутри своей плашки — не вылезает, не режется, не переносится уродливо; **(c)** на экране блица НЕТ пустых плашек/полос и элементов не из макета (исчерпывающий набор видимых); **(d)** мысль-текст карты читается целиком; **(e)** ничего не обрезано краем 16:9; **(f)** стиль/палитра как в styleframe. |
| 7 | regressions | Все тесты зелёные; новые — по ОТРИСОВАННОМУ результату (Слой 2): баннер и карта НЕ видимы одновременно (нет наложения); подпись кризис-плашки влезает (drawn width текста ≤ ширины плашки, не clipped); исчерпывающее перечисление активных видимых элементов блица = ожидаемый набор (пустая полоса = провал). `studio-go suite` HEADLESS зелёный. |

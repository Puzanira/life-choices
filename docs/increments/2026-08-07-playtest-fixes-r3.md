## 1. Пересказ дизайна (9 пунктов основательницы, дословно по чату)

1. **Здоровье-туториал.** Открытие здоровья (30) — старый жёлтый S5-хинт → переодеть
   в стиль D-модалок: затемнение + КРУПНЫЙ бар здоровья + рассказ Ведущего в облачке
   + окно-задача на плашке-взрыве. Контрола у здоровья нет (лечат выборы за деньги) —
   закрытие по зелёной (кнопка в стиле арт-пака: CTA как на опенере, не «ПОНЯТНО» на
   синей). Тексты: рассказ/задача в тоне Цезаря из текущего содержимого хинта
   («годы берут своё — здоровье тает само», «лечись выборами за деньги — если
   накопил») — В host-content §4 как КАНОН-ЧЕРНОВИК с пометкой «основательница
   правит свободно».
2. **Блиц-туториал.** Кризис стартует без объяснений → входной D-стиль экран:
   рассказ = CrisisAnnounce («КРИЗИС СРЕДНЕГО ВОЗРАСТА! БЛИЦ!»), задача = правила
   («5 мыслей по 5 секунд — жми ВСЁ НОРМАЛЬНО, кнопки прыгают местами»; сведи с
   crisis-content.md), старт по зелёной; кризисный таймер стоит, пока экран висит.
3. **Депрессия:** (а) зазор — НЕ встык за блицем: минимум N обычных карточек между
   кризисом и депрессией (тюнимо, дефолт 3–4; расширение пейсинг-правила);
   (б) входной D-стиль туториал (рассказ = DepressionAnnounce «ТЁМНАЯ ПОЛОСА…»
   глухо, задача = «Лови пульс: жми <КОНТРОЛ> в момент вспышки — пять попаданий
   вернут краски»; старт по зелёной, всё стоит); (в) на самом экране депрессии —
   подсказка контрола + клавиша при эмуляции, пульс-индикатор заметнее;
   (г) ⚠ ОТКРЫТЫЙ ВОПРОС ОСНОВАТЕЛЬНИЦЕ: контрол ловли — сейчас ЗЕЛЁНАЯ (код),
   в спеке встречи «!». Реализовать конфигурируемо/при выборе — СПРОСИТЬ; до ответа
   оставить зелёную и написать её в текстах.
4. **Панч плашек — только на принятый ответ.** В депрессии/туториолах/подсказках/
   блокировке зелёная и красная НЕ должны анимировать плашки ДА/НЕ НАДО (игра ввод
   глушит, а панч играет). Единое правило на accepted-семантике + тест по состояниям.
5. **Выгорание:** (а) стиль арт-пака (рассказ Ведущего + окно-задача + крупная
   красная батарея вместо программного «ВЫГОРАНИЕ!»); (б) первый раз — туториал с
   ПАУЗОЙ дренажа (умереть, читая правила, нельзя), повторные — короткая плашка без
   блокировки; (в) грейс-период после выхода (несколько секунд без дренажа, тюнимо
   5–8 с) — повторное выгорание встык запрещено; (г) текст задачи: «Зажми датчик
   высоты и держи, пока не придёшь в себя» + клавиша при эмуляции.
6. **BLOCK$-баннер и чип цены — ПОВЕРХ плашек ДА/НЕ НАДО** (сейчас кнопки их
   перекрывают по z). + sibling-ассерт.
7. **Дрейф отношений быстрее.** Сейчас до расставания при бездействии >1 минуты —
   не наказывается. Подобрать симом: из зелёной середины до разрыва при полном
   бездействии за ~30–45 с; удержание ↑ по-прежнему уверенно вытягивает (нетто
   проверить тем же симом). Числа тюнимые, механика/пороги зон не меняются.
8. **Порядок «начать встречаться».** Карточка приходит ПОСЛЕ открытия шкалы
   отношений — нелогично. Найти её в scenes.csv, обеспечить порядок «встречаться →
   OPEN:Отн» (окно возраста/сэмплер; канон-возрасты без нужды не трогать) +
   пейсинг-тест на порядок.
9. **Отклик пропущенного звонка:** трубка уезжает «поникшей» (притушенная, без
   дуг — контраст с уездом после успеха), + реплика Ведущего в тоне («Малыш ждал…» —
   канон-черновик в host-content, основательница правит). Успех уже салютует.

## 2. Done contract

| # | Class | Criterion |
|---|-------|-----------|
| 1 | boots | Старт ок. |
| 2 | player path | Все спецрежимы (здоровье/блиц/депрессия/выгорание-1й-раз) входят через D-стиль экран с паузой; на самих экранах написано, ЧЕМ играть (+клавиша при эмуляции). |
| 3 | interaction path | Депрессия не встык за блицем (≥N карточек); выгорание не встык за выгоранием (грейс); баннер/чип поверх кнопок; панч только на принятый ответ; пропуск звонка виден (трубка+реплика). |
| 4 | failure/restart path | Пауза туториалов не даёт умереть под ними; рестарты чисты; дрейф отношений: бездействие → разрыв за ~30–45 с, удержание спасает. |
| 5 | observability | Тексты всех новых экранов — канон-черновики в host-content §4 (помечены для правки основательницей); «начать встречаться» до открытия шкалы. |
| 6 | design | Новые экраны собраны из готовых блоков D-стиля (затемнение/крупный виджет/облачко/плашка-взрыв/CTA) — композиционно как принятые модалки. |
| 7 | regressions + Слой-2 | Тесты: входы всех режимов через экран (+пауза), зазоры, панч-состояния, z-порядок, дрейф-сим, порядок карточек, отклик пропуска. Suite HEADLESS зелёный. |

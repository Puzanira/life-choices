## 1. Пересказ дизайна

Пункты основательницы, дословно:

1. **«Тяжело играется — не понимаю про две секунды. Давай просто "зажать датчик
   высоты", пока батарейка не заполнится».** РЕДИЗАЙН МЕХАНИКИ ЭНЕРГИИ: ритм-гейт
   (BreathRhythm, импульсы на подъёме) УМИРАЕТ. Новая механика: **датчик поднят
   (HeightA выше порога) → энергия растёт с постоянной скоростью; отпустил →
   рост прекращается, обычный дренаж продолжается.** Механика едина везде:
   туториал, обычный ход, выгорание (выход из выгорания — тоже удержанием).
   Скорость роста — тюнимая; в туториале батарея с типового старта заполняется
   за ~4–6 с удержания. Условие туториала: «пока батарейка не заполнится» —
   батарея ДО ПОЛНОЙ (≈100%). Тексты: задача «Зажми датчик высоты — держи, пока
   батарейка не заполнится» (канон host-content §4 обновить, старое зачеркнуть);
   подсказка эмуляции «зажми Q». Отклик «не в ритм» из r1 — снять (нечему
   отклоняться). Требование «шкала требует активного ввода» сохранено: рост
   ТОЛЬКО при физически поднятом датчике.
2. **«Крутить ручку денег надо дольше на туториале — слишком быстро пропадает».**
   Условие туториала денег: с 1 принятого тика → **N тиков** (тюнимо, дефолт
   ~6–8 — пара секунд верчения; монеты капают на каждый тик — само по себе
   прогресс-фидбек).
3. **«Убрать полосу прогресса в туториалах»** — полоска удержания/прогресса
   снимается со ВСЕХ D-модалок. Прогресс показывают сами виджеты (батарея
   наполняется, монеты капают, маркер в зоне). Условие отношений (зона 40–75,
   1.5 с) остаётся — без полоски.

  **MAJOR — падеж в строке исхода.** На кадре стояло «Ты дожил до 41 год»: предлог «до»

  единицей сохранены.

  | N | до N … | | N | до N … |
  |---|--------|-|---|--------|
  | 1 | го́да | | 41 | го́да |
  | 2 | лет  | | 78 | лет  |
  | 5 | лет  | | 100 | лет |
  | 11 | лет (исключение) | | 101 | го́да |

  | что | hex | откуда |

  | сырой тинт `Image.color` | `#22409C` | токен, поделённый на заливку спрайта (`OnBarTrack`) |

  Δ модель↔пиксель ≤ 2/255 — не ошибка тинта: проект рендерит в **линейном** цветовом

## 1. Пересказ дизайна

- **§3 (meeting-revisions) — таймер ответа по фазам возраста** вместо единого 5 с:
  1–19 лет → **10 с** · 20–29 → **8 с** · 30–100 → **6 с** · блиц (кризис) → **5 с**
  (блиц перебивает фазу). Таймер = функция возраста; точки с зашитыми 5/2–3 с — в
  Game.cs. Механика таймаута («молчание = случайный выбор» / INVERT в импульсе) не
  меняется — только длительности.
- **§5a — купол-таймер сверху по центру** вместо круглого кольца: полусфера свисает
  с верхнего края (бокс ≈ 760,0,400,130, центр по X 960), дуга-остаток убывает за
  таймер фазы, цвет YELLOW → RED_BRIGHT в последнюю ~1 с, обводка INK. Отдельного
  спрайта нет — рисовать процедурно в стиле арта (build-spec §2). На паузах
  (туториалы/подсказки) купол заморожен. Круглое кольцо (252,590) снять.

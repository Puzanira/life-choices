## 1. Пересказ дизайна

**§5b (meeting-revisions) + build-spec §E.** Эталон «Экран звонит телефон.png».

- **Покой:** трубка `hf_phone copy.png` (БЕЗ дуг — asset-map: две позы одной трубки)
  спрятана — торчит из-за левого края (`-30,370,190,350` ориентир; map §2 замер
  `-62,394,191,349`), тёмно-синяя, статична.
- **Звонок:** трубка выезжает внутрь (до `20,330,240,400`, наклон ≈ −14°), спрайт
  `hf_phone.png` (красные дуги-вибрация ЗАПЕЧЕНЫ — §12-7: пульс дуг заменяем
  качанием), качание rot ±6° период ~0.12 с. Окно поднятия — **5 с**.
- **Поднять:** кнопка «!» (`BangButton`, dev-клавиша `1` — ChildPress). Успех:
  трубка успокаивается и уезжает (0.3 с), **салют звёзд** (StarBurst() уже готов).
- **Не поднял за 5 с:** уезжает + **+1 к счётчику пропущенных**; при **2+** —
  ветка «плохой родитель» (в Game уже есть: 2+ = плохой родитель).
- **Частота:** раз в ~15–25 с (текущий канон интервала сохранить).
- Старую вспышку кнопки-ребёнка (жёлтая кнопка со звездой, glow, «жми по вспышке»)
  СНЯТЬ вместе с её подсказками; туториал-тексты уже канон («Когда телефон слева
  зазвонит — жми «!»…», host-content §4).
- Механика счёта/штрафов в Game уже есть (ChildPress/пропуски) — драйверная часть
  переключается со вспышки на трубку; изменения Game.cs — ТОЛЬКО если текущее окно
  вспышки ≠ 5 с (привести к 5 с по спеку §5b — это спековое число).

**Шаг 0 (гигиена гейта):** зафиксить флак `DriverLiveHudTests.HealthHint_…` —
колода сэмплируется `new System.Random()` на каждый прогон; тест должен получать

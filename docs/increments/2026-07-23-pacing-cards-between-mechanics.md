## 1. Пересказ дизайна

**Проблема (плейтест):** механики открываются близко по возрасту — деньги @18,
отношения @20, энергия @25, здоровье @30 — а сэмплер тянет всего **3** обычные
карты на всё окно молодости (`YoungTarget=3`), да и в пуле их мало в 18–29. Итог:
деньги→подсказка, почти сразу отношения→подсказка, потом энергия→подсказка, между
ними ничего. Каждая веха ещё и зажигает **жёлтый рубрик-баннер** (Bulb-полоса
1600×240 по центру) — «оранжевый блок посреди экрана», который сыпется подряд.
Играть и вникать невозможно.

**Решение (направление основательницы — возрасты как есть):**
1. **~32 новые обычные карты-филлеры** (FA 18–19 ×10, FB 20–24 ×10, FC 25–29 ×8 +
   30–40 ×4) — чистый флейвор, маленькие Δ, без новых механик/таймлайна/фатала.
   Вписаны в `scenes.csv`.
2. **Разбить окно молодости сэмплера на под-окна** young-early(18–19) /
   young-mid(20–24) / young-late(25–29) с целью ~8–10 карт в каждом; поднять mid;
   поднять `MaxDeck` под более длинную жизнь. Возрастная сортировка + полный пул →
   money@18 → ~8–10 карт 18–19 → relationships@20 → ~8–10 карт 20–24 → energy@25 →
   ~8–10 карт 25–29 → health@30.
3. **Баннер/подсказки перестают сыпаться** — следствие пейсинга (вехи разъехались),
   плюс при необходимости баннер только на крупные вехи.

Механика самих шкал/выборов НЕ меняется — только плотность и порядок колоды.

## 2. Done contract

| # | Class | Criterion |
|---|-------|-----------|
| 1 | boots | Старт без ошибок; колода грузится с новыми картами. |
| 2 | player path | Полный прогон: между открытиями деньги/отношения/энергия/здоровье проходит ≥8 обычных карт; подсказки/баннер не подряд. |
| 3 | interaction path | Все выборы/шкалы работают как раньше; новые карты — валидный ДА/НЕТ + Δ. |
| 4 | failure/restart path | Без регрессий; длина жизни в разумных рамках. |
| 5 | observability | Игрок успевает вникнуть в каждую механику. |
| 6 | content | 32 новые карты парсятся, безусловные (в пуле), Δ маленькие и по знаку верные (трата=−₽), тон совпадает, без запрещённых флагов. |
| 7 | regressions + **Слой-2 ПЕЙСИНГ-ТЕСТ** | Все прежние тесты зелёные; новый детерминированный тест: в симулированном прогоне (несколько сидов) между последовательными вехами-открытиями механик (money/relationships/energy/health reveal) выпадает **≥8 обычных (не-таймлайн/не-система) карт**; и НЕТ двух подряд таймлайн/подсказка-карт. `studio-go suite` HEADLESS зелёный. |

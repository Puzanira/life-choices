## 1. Пересказ дизайна

В игре звука нет вообще. Дизайн-сессия отобрала файлы (все CC0) и решила:
зал/аплодисменты СНЯТЫ, эмбиент и вехи возраста — намеренно без звука,
калимба — голос игры (ответы, «алло», второй шанс, лечение, расставание),
Ведущий — шесть пиццикато по тонам реплик, финал — три конца (скрипка/казу/
обрыв пластинки), энергия — один жест зарядки. Главный художественный приём —
ДЕПРЕССИЯ: весь микс уходит «в вату» (лоу-пасс), возврат по ступеням попаданий.

Внедрение:

1. **Аудио-слой в драйвере**: единая точка проигрывания (SFX + луп-каналы),
   импорт файлов из docs/assets/audio-picks/ в Assets (структура по группам
   манифеста), маппинг событие → клип по манифесту, «намеренно без звука» —
   список-исключение, НЕ дыра.
2. **Разводка событий**: подписки на существующие события Game/GameDriver
   (ответы/раздача/купол/BLOCK$/крутилка/монета/тревоги/энергия-жест/
   выгорание/отношения/расставание/второй шанс/здоровье/телефон/салют/
   туториалы/блиц/импульс/депрессия/опенер/финал-по-типу-конца/рестарт).
   Каждое событие манифеста должно иметь подписку или явную пометку «нет
   события в коде» в чекпоинт-логе (не выдумывать событий).
3. **Фильтр депрессии**: лоу-пасс на весь микс по спеке манифеста; вход —
   «в вату», каждое попадание пульса возвращает ступень (5 ступеней), выход —
   «мир снова включили». Депрессионный одинокий удар сердца — вне фильтра.
4. **Лицензии**: атрибуции уже в манифесте; в билд файлы кладутся как есть,
   лицензии не переоформлять.

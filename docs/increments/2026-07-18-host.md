## 1. Пересказ дизайна

**Ведущий оживает** — приторно-бодрый голос шоу (тон Цезаря Фликермана) начинает
комментировать твою жизнь и объявлять её «рубрики».

**Реплики-облачка (на ~30–40% выборов, не на все):** после ответа всплывает
жёлтое облачко (спрайт `bubble.png`, S3) с короткой репликой (1–3 слова),
на пару секунд. Источник по приоритету:
1. **именная** — из колонок «Ведущий ДА/НЕТ» карточки для выбранной стороны
   (уже в CSV: `CH01`=ДА «Крепкий орешек!», `YA01`=ДА «Умница!»/НЕТ «Бунтарь,
   обожаю!», `CH02`=ДА «Ну, спасибо за игру!»/НЕТ «Пронесло!» …);
2. если именной нет — **общий пул по тону выбора** с вероятностью (чтобы вышло
   ~30–40% всего): успех / риск / абсурд / осторожность / фатал / пропуск.
   Тексты пула — из GAME_SPEC (черновики), финально даёт дизайн-агент.

**Баннеры-рубрики (S4):** на одноразовых вехах (`TIMELINE`) Ведущий объявляет
рубрику жизни — крупный баннер с фанфарным настроением: **ПОРА ЗАРАБАТЫВАТЬ!**
(18) · **ПЕРВАЯ ЛЮБОВЬ!** (20) · **ПЕРВАЯ УСТАЛОСТЬ!** (25) · свадьба · ребёнок ·
**КРИЗИС СРЕДНЕГО ВОЗРАСТА!** (`CR00`, вне scope-кризиса — но баннер к вехе
уместен). Баннер — короткий (не требует ввода), затем показывается сама
карточка/подсказка. Точные названия рубрик — дизайн-агент (owner стартует на
черновиках GAME_SPEC).

**Тон выбора** для пула: fatal — по флагу FATAL; пропуск — таймаут; остальное —
грубой эвристикой по Δ (сильный плюс → успех, крупный минус/риск → риск, абсурд —
кек-тип), пока дизайн-агент не даст явные теги (если решит).

> Вне scope: искажение реплик в Депрессии (кризис-блок), настоящая анимация
> конфетти/фанфар (звук — отдельный инкремент; конфетти статикой/простое),
> живые отношения/ребёнок, кризис-механика. Спрайт облачка подключаем; полноценный
> художественный проход по репликам — за дизайн-агентом.

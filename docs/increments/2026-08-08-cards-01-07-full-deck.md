## 1. Пересказ дизайна

Колода растёт 85 → ~243: плотность жизни выравнивается (было 46 карточек на
молодость и 20 на остальные 70 лет). Посадка по утверждённым докам:

1. **Отрезок 1 (детство)** — cards-script-01: детство перестаёт быть одинаковым.
2. **Отрезок 2 (юность)** — cards-script-02: юность перестаёт бить в пустоту.
3. **Отрезок 3 (молодость)** — cards-script-03: первое расставание рвёт
   по-настоящему (BREAK-цепочки).
4. **Отрезок 4 (25–29)** — cards-script-04: свадьба обрастает жизнью (PRENUP,
   развод −60 ₽, ветка «детей не будет» EXCL:реб + MULT:Дн=x1.3, кек-карточки
   разные, пул 19 → 48).
5. **Отрезки 5–7 (30–100)** — cards-script-05…07: 30–39 (7→30), 40–55 (7→27),
   56–100 (6→27); чейн LT05↔CH15; LT08 получает некролог; MD06 «второй шанс»
   (шкала отношений открывается заново) — РЕАЛИЗОВАТЬ механику, она была
   hard-excluded в отрезке 0.
6. **Формат строк** = колонки scenes.csv; в доках метки «НОВАЯ / ПРАВКА <ID> /
   БЕЗ ИЗМЕНЕНИЙ». Обе копии CSV байт-в-байт.
7. **Пейсинг**: вехи/канон-возрасты не трогать; «начать встречаться → OPEN:Отн»
   порядок держится; ≥8 карточек между открытиями механик; депрессия ≥4 после
   кризиса; окна возрастов из доков.

## 2. Done contract

| # | Class | Criterion |
|---|-------|-----------|
| 1 | boots | Старт ок; обе копии CSV идентичны; ~243 строки парсятся без ошибок (валидатор: ID уникальны, флаги известны, чейны замкнуты). |
| 2 | player path | Забег проходим на нескольких сидах: вехи присутствуют, филлеры по окнам, длина забега НЕ выросла против отрезка 0 (инвариант сэмплера). |
| 3 | interaction path | Новые механики контента живут: BREAK-цепочки рвут; PRENUP имеет носителя и гасит развод; EXCL:реб ↔ ипотека взаимоисключаются на живой колоде; MD06 второй шанс открывает шкалу заново; кредитные — по-прежнему единственный минус. |
| 4 | failure/restart path | ГЛАВНЫЙ ГАРД ЖИВ: «умеренный игрок ≥70» на ПОЛНОЙ колоде (лингеринг-сим по сидам); пассивный умирает рано; рестарты чисты. |
| 5 | observability | Некролог-7 собирается из новых строк без дыр (вехи первыми); реплики Ведущего новых карточек в пулах по тону; debt-пул стреляет на кредитных. |
| 6 | design | Финал/карточки композиционно без регрессий (тексты новых карточек не рвут плашку: worst-case длины под гардом ширины). |
| 7 | regressions + Слой-2 | Пейсинг/баланс-тесты расширены на полную колоду; suite HEADLESS ×2 зелёный; флак Finale_DevConfirmKey чинить сидированием при выстреле. |

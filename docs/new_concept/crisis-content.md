# Кризис / Депрессия / Тон — спека и контент

Для будущих ночных инкрементов (Блиц, Импульс, Депрессия, теги тона). Канон.
Тексты мыслей/карт кризиса уже в `scenes.csv` (`CR01`–`CR08`); тут — механики и
добавки.

## 1. Депрессия (`CR09`) — мини-игра выхода

Закрывает дыру в GAME_SPEC («лечится мини-игрой», но не описано как).

- **Экран:** уже решённое ч/б + зерно, звук приглушён/минорит. По центру —
  еле заметный медленный **пульс** («сердцебиение»/тусклый огонёк), появляется
  редко: раз в **~2.5–3 сек**, окно попадания ~0.6 сек.
- **Механика ВЫХОДА — «собраться», намеренно противоположна «дыханию» энергии**
  (там частый ровный ритм). Здесь — **редкие, медленные, точные нажатия одной
  кнопки** (`CHILD_PRESS`/`CONFIRM`) строго в момент тусклого пульса. Ритм
  сбивчивый и медленный — надо ждать и ловить, а не долбить.
- **Прогресс:** каждое попадание **возвращает немного цвета** экрану
  (десатурация спадает ступенькой ~20%). Нужно **5 попаданий** → цвет полностью
  вернулся → Депрессия снята, игра продолжается (≈15–20 сек при аккуратной игре).
- **Промах** (не нажал в окне или нажал мимо): прогресса нет, цвет чуть уползает
  обратно в серость (−1 «ступенька», не ниже нуля). **Смерти в Депрессии нет** —
  из неё только выходят; шкалы на паузе, пока она активна.
- **Ведущий:** глухой/искажённый, редкие короткие реплики: «…ну же…» ·
  «…почти…» · «…вот так…» — тон подсева, без восторга.

## 2. Блиц (`CR00`–`CR05`) и Импульс (`CR06`–`CR08`) — подтверждение

Спека подтверждена как есть:
- **Блиц:** 5 мыслей подряд, таймер **2 сек** на мысль; две кнопки
  **«О НЕТ»** / **«ВСЁ НОРМАЛЬНО»**; позиция «ВСЁ НОРМАЛЬНО» **рандомится**
  каждый раз. Промах / «О НЕТ» / не успел = **+1 провал**.
- **Импульс** (только при **≥2 провалах**): `CR06`–`CR08`, флаг `INVERT`
  (молчание = ДА) — надо успеть нажать **«СПАСИБО, НЕ НАДО»**. При 0–1 провале
  импульс не запускается.
- **Тексты — уже в `scenes.csv`:** мысли `CR01`–`CR05`, импульс-карты
  `CR06`–`CR08`. Доп. контент не требуется, кроме реплик ниже.

**Реплики Ведущего для блица** (быстрые, глумливо-подгоняющие, поверх мыслей):
«Быстрее!» · «Соберись!» · «Не тормозим!» · «Улыбаемся!» · «Всё хорошо, правда?» ·
«Держим лицо!»

## 3. Колонка «Тон» — маппинг ID→тон (опционально)

Для карт, где эвристика по знаку Δ промахнётся (кек тратят деньги → читаются как
«risky/негатив», хотя они `absurd`; соблазны с плюсом к деньгам читаются как
«успех», хотя они `risky`). `fatal` берётся по флагу, `skip` по таймауту — их
здесь нет. Именная реплика из `Ведущий (ДА)/(НЕТ)` всё равно главнее.

| ID | Тон | Почему эвристика мимо |
|----|-----|------------------------|
| `KEK01`–`KEK05` | `absurd` | Δ = −деньги, но это кек, не «плохой выбор» |
| `RND01` (лёгкие деньги) | `risky` | Δ = +деньги → ложно «успех» |
| `RND04` (крипта) | `risky` | Δ = ±деньги → ложно нейтрально |
| `RND05` (роман) | `risky` | Δ = −отношения → просто «негатив», а тут соблазн |
| `YA02` (бросить универ) | `risky` | Δ = ±деньги |
| `YA04` (кредит) | `risky` | Δ = +деньги → ложно «успех» |
| `CH01` (съесть жука) | `absurd` | Δ = +здоровье → ложно «успех» |
| `CH06` (соврать про вазу) | `absurd` | нейтральная Δ |
| `CR07` (мотоцикл 200) | `absurd` | импульс-абсурд |
| `CR08` (Шри-Ланка налысо) | `absurd` | импульс-абсурд |

Остальные карты — эвристикой по знаку Δ (плюс к ключевой шкале → `positive`,
минус → `risky`/`cautious`). Формат колонки: `Тон` = `positive|risky|absurd|cautious`,
пусто = вывести эвристикой.

## Легенда колонок таблицы
1. **ID** — стабильный идентификатор (для ссылок и цепочек).
2. **Карточка (как звучит)** — текст для игрока, тон приторно-бодрого ведущего.
3. **Когда** — возраст и/или условие появления.
4. **Тип** — категория карточки.
5. **ДА — последствия (механика)** — **что меняется в игре**: какая карточка появляется/гаснет, какая шкала или крутилка открывается, что триггерится или блокируется, мгновенный конец и т.п. **Не флейвор шоу** (реакция шоу/конфетти живёт отдельно, см. ниже).
6. **ДА — Δшкалы** — числовой эффект на шкалы.
7. **НЕТ — последствия (механика)** / 8. **НЕТ — Δшкалы** — то же при отказе.
9. **Ведущий (ДА)** / 10. **Ведущий (НЕТ)** — короткая именная реплика-облачко Ведущего на выбор (см. ниже). Пусто = берётся из общего пула по тону.
11. **Некролог ДА** / 12. **Некролог НЕТ** — строка в финальный рассказ о жизни под каждый выбор. **Правило:** каждая строка — законченное предложение в прошедшем времени; **начинать по-разному, НЕ всегда с «Вы…»** (иначе склейка звучит уныло), так чтобы выбранные строки, склеенные по порядку, читались как связная биография. Финальный экран собирается: «Причина конца…» + «Но не переживайте! Ведь вы родились у прекрасных родителей. …» — детали в [`game-design.md`](game-design.md) §17. Незначимые карточки (интро, кек, блиц) в некролог не попадают → `—`.
13. **Флаги** — служебные метки для реализации.
14. **Длительный эффект** — машиночитаемые долгие эффекты (множители дохода,
    рассрочки), которых нет в разовой Δ-колонке. Пусто = `—`. Грамматика (через `;`):
    `MULT:Дн=x2 FROM:25` (множитель дохода с возраста) · `MULT:Дн=x5|0` (случайно,
    с `RANDOM_OUTCOME`) · `DRAIN:Дн=-0.3/s DUR:10y` (дренаж N лет; разовый взнос
    остаётся в Δ). Заполнено: `YA01`, `YA02`, `YA06`, `YA04`, `MD04`.
15. **Тон** — тег тона для реплики Ведущего: `positive`/`risky`/`absurd`/
    `cautious`. Пусто = вывести эвристикой (по знаку Δ; `fatal` по флагу, `skip`
    по таймауту). Заполнено только там, где эвристика мимо (кек, соблазны,
    абсурд): `CH01`,`CH06`,`YA02`,`YA04`,`CR07`,`CR08`,`RND01`,`RND04`,`RND05`,
    `KEK01`–`KEK05`. Маппинг и обоснование — `crisis-content.md` §3.

> **Реакция шоу ≠ последствия.** Яркость/депрессивность обёртки (конфетти, фанфары, потухание) — это глобальный отклик на общее состояние игрока (настроение/здоровье), а не эффект конкретной карточки. Поэтому в колонках «последствия» этого нет — там только механика.

### Шкалы (сокращения)
- **Здр** — Здоровье (ноль = смерть) · **Эн** — Энергия (ноль = смерть) · **Дн** — Деньги · **Отн** — Отношения (держать в зоне 40–75%) · **Реб** — Ребёнок.
- Отдельной шкалы «настроения» нет: тон шоу — это отклик на общее состояние (здоровье/отношения/энергия).

### Нотация Δ
Качественная шкала −3…+3 относительно обычного «поддержания». `+2` рост, `−2` падение, `±3` рандом в обе стороны, `—` нет эффекта. Для Отношений «+» = ближе к идеальной зоне. **Точные числовые значения — в [`game-design.md`](game-design.md);** здесь Δ только для быстрого чтения.

### Флаги
`NOCONS` без последствий (выбор есть) · `FORCED` реального выбора нет — веха/объявление; UI не изображает агентность, в некролог не идёт (≠ NOCONS) · `FATAL` мгновенный конец + причина финала · `BLOCK$` заблокирована без денег · `DELAY(n)` отложенное последствие через ~n лет · `CHAIN→ID` тянет карточку · `OPEN:шкала` открывает шкалу (+ обучающая подсказка, см. GDD §22) · `TIMELINE` одноразовое событие · `RANDOM_OUTCOME` случайный исход карты (напр. ×5/0) · `RANDOM_TRIGGER` случайно, появится ли карта вообще · `INVERT` в импульс-раунде молчание = ДА · `BLITZ` кризис-блиц: 2 сек, найти «ВСЁ НОРМАЛЬНО» · `ROND` «неважная», можно не тащить в финальный эпилог · `ZONE` шкала отношений: плохо и мало, и много.

> **Изменения канона 2026-07-18** (см. `docs/design-tasks/2026-07-18-answers.md`):
> добавлен `FORCED` (`YA05`/`CR00`/`CR09`); `RANDOM` разделён на `RANDOM_OUTCOME`

> порог `Здр<50%`; добавлена колонка «Длительный эффект».

## Реплики Ведущего (speech bubbles) — новая механика

Тон — **Цезарь Фликерман из «Голодных игр»**: приторно-восторженный, чуть глумливый, всегда на публику. На **некоторые** выборы (не на все — иначе замыливается) поверх экрана всплывает жёлтое облачко с короткой репликой в 1–3 слова.

**Два источника реплик:**
1. **Именная** — прописана у конкретной карточки в колонках «Ведущий (ДА)» / «Ведущий (НЕТ)». Приоритет.
2. **Общий пул по тону** — если у карточки именной реплики нет, движок берёт случайную из пула по тегу тона выбора.

**Общий пул (по тегу тона):**
- **Успех / смелость** — «Вот это да!», «Красавчик!», «Уважаю!»
- **Риск / сомнительно** — «А вот это зря…», «Ну-ну.», «Смело!»
- **Абсурд / кек** — «Да вы шутник!», «Оригинально…», «Гениально! (нет)»
- **Осторожность / отказ** — «И правильно!», «Скучноватоо…», «Перестраховщик!»
- **Фатальный выбор** — «Ох.», «Чтож, спасибо за игру!», «…»
- **Пропуск (не успел ответить)** — «Молчание — тоже ответ!», «Задумались? Бывает.»

**Реализация:** у каждого выбора — тег тона (`positive` / `risky` / `absurd` / `cautious` / `fatal` / `skip`). Именная реплика перекрывает пул. Частота показа ~30–40% выборов, чтобы не приедалось. В состоянии **«Депрессия!»** реплики гаснут или звучат искажённо/минорно (тот же текст, унылый тюн).

## Механики по возрасту (справка)
- **До старта** — опенер-экран (ироничные правила), затем `I02`/`I03`.
- **0–17** — только карточки (~7–8, ~45 сек), много времени на чтение. Первые карточки (`I02`, `I03`) = `NOCONS`, для втягивания. На `I03` запускается таймер возраста, музыка и анимация движения.
- **18** — `OPEN:Дн` через подсказку «теперь у вас есть работа»; карточка `YA01` — только развилка «универ» (множитель).
- **20** — первое предложение встречаться (`YA03`) → `OPEN:Отн` (+ подсказка).
- **25** — «первая усталость» (`YA05`) → `OPEN:Эн` (+ подсказка).
- **28–32** — предложение свадьбы (`MD01`).
- **свадьба +2** — предложение ребёнка (`MD02`) → `OPEN:Реб` (+ подсказка).
- **30** — Здр начинает падать (+ подсказка про здоровье).
- **~40** — если первые отношения потеряны — второй шанс (`MD06`).
- **45–50** — кризис → **Блиц** (`CR00`–`CR05`); при ≥2 промахах — импульс-раунд (`CR06`–`CR08`); после — возможна «Депрессия!» (`CR09`).
- **55–70** — болезни, стареющие родители, дети выросли (`LT01`–`LT07`).
- **Финал** — экран-некролог: 100 лет (весёлая/спокойная/одинокая старость) / Здр или Эн = 0 (выгорел) / `FATAL` (дичь).

> **Время — событийное:** длину забега задаёт число карточек (~6 сек/карта), а не «лет в секунду». Дренажи считаются по реальным секундам. Подробности — `game-design.md` §6.

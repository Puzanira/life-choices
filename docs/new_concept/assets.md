# Ассеты — список и спецификация

> Экран: **16:9**. Спрайты — **PNG с прозрачностью**; фоны — под финальное разрешение (напр. 1920×1080).
> Стиль зафиксирован в [`../assets/style/`](../assets/style/): `styleframe-03.png` — текущая рабочая заглушка (яркое чистое ТВ-шоу, тёплый санбёрст, толстые белые обводки, слэш-плашки ответов).
> Приоритет: **P0** — нужно для играбельного прототипа с артом; **P1** — полный набор; **P2** — доп. полировка.

## Фоны / экраны

| Ассет | Приоритет | Заметки |
|-------|-----------|---------|
| Задник сцены шоу (санбёрст) | P0 | тёплые лучи, звёзды; фон приглушён, чтобы UI читался |
| Экран-опенер | P1 | заставка с правилами (текст в GDD §3) |
| Состояние «Депрессия» | P1 | тот же задник, обесцвеченный в ч/б + зерно |
| Экран-финал (некролог) | P1 | под причину конца + текст истории |

## Иконки карточек (P2, позже)

Жук, кот, дерево, розетка, ваза, кольцо, малыш, мотоцикл, крипта, порошок, крыша-селфи и т.д. На старте достаточно общей рамки + пары ключевых.

## Шрифт

Жирный дисплейный санс с кириллицей — кандидаты: **Bebas Neue**, **Anton**, **Fredoka**, **Shrikhand** (проверить кириллицу). Прототип использует системный жирный санс как заглушку.

## Аудио (отдельно)

Джингл-опенер, фанфары на рубрики, фоновая петля + её искажённая «депрессивная» версия, клики ответов.

## Генерация ассетов

Стиль-фреймы делались через Higgsfield (`nano_banana_pro`, 16:9, ~2 кредита/шт — хорошо рендерит кириллицу). Для консистентности можно подавать `styleframe-03.png` как reference-input.

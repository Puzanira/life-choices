Полный набор экранов и состояний игры в визуальном языке телевикторины 70–80-х — как реализуемые макеты 16:9, а не только текст. Каждый экран собран из общего UI-кита, сопровождён спекой компонентов, заметками под Unity и промптом генерации арта.

Экран 16:9 (1920×1080) Стайлфрейм-эталон: styleframe-03 Ответ: ДА / СПАСИБО, НЕ НАДО 12 экранов + UI-кит
Как пользоваться. Открой в браузере — все кадры рендерятся вживую и масштабируются; можно скриншотить под задачу. Макеты плейсхолдерные по контенту, но точные по раскладке, цветам и компонентам — цель снизить «сырость» на входе в Unity. Финальный арт генерится по промптам (Higgsfield / nano_banana, reference = styleframe-03.png) и кладётся в ту же раскладку. Шрифт в макете — системный тяжёлый санс как заглушка; в проде — Fredoka / Anton / Shrikhand (проверить кириллицу), инлайнить как @font-face.

Заметки под реализацию в Unity

Чтобы макеты перенеслись 1-в-1, а не «на глаз».

Холст и раскладка
  • Canvas 1920×1080, CanvasScaler = Scale With Screen Size, reference 1920×1080, match 0.5.
  • HUD-ряд — верхний якорь, горизонтальный Layout Group, gap ≈ 1.6% ширины.
  • Карточка-маркиза — центр (anchor 0.5/0.5, чуть выше центра). Плашки ответа — нижний якорь, HorizontalLayout.
  • Таймер-кольцо — верхний центр; реплика Ведущего — свободный якорь у края.
Спрайт vs код
  • Спрайты (из промптов / арта): санбёрст-задник, звёзды, рамка-маркиза с лампочками, иконки (сердце, молния, монета, ₽), баннеры-рубрики.
  • Код/UI: заполнение полос (Image fill), балансир-бегунок, таймер-кольцо (radial fill), счётчик денег (TMP tabular), реплики/конфетти (частицы).
  • Плашки ДА/НЕТ — 9-slice спрайт + TMP; лёгкий поворот ±2°.
Цвета и шрифт (перенести как токены)
  • Кобальт #2f54c8 / глубокий #1f3a96 / контур #141a3d.
  • ДА #5cbf5f · НЕТ/здоровье #e8443a · энергия/лампочки #f6c945/#ffd873.
  • Санбёрст: оранж #f2a23e · жёлтый #f8d24c · зелёный #aacd68.
  • Шрифт — тяжёлый дисплейный санс с кириллицей (Fredoka / Anton / Shrikhand); проверить глифы, задать outline+shadow как в макете.
Состояния экрана (материал/пост-эффект)
  • Норма: полная насыщенность, конфетти при хорошем состоянии.
  • Выгорание: лёгкое приглушение + «тяжёлая» крутилка (геймплей, не только визуал).
  • Депрессия: grayscale + зерно (полноэкранный пост-эффект/материал), звук минорит.
  • Реакция шоу на состояние (яркость↔уныние) — общий контроллер поверх сцены.

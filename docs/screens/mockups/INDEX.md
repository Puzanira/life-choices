# Эталонные макеты экранов — «Спасибо, не надо»

**Это ЭТАЛОН для дизайн-гейта** (сверка отрисованного экрана с макетом).
PNG 1920×1080 (16:9), стиль — `docs/assets/style/styleframe-03.png` + токены
`#kit`. Черновой `docs/screens/index.html` — опора, НЕ эталон; годный эталон
здесь. Перегенерация — `_generate.py` (Pillow, реюз спрайтов `docs/assets/sprites/`
+ шрифт Rubik). Инвариант всех макетов: **весь текст целиком внутри плашки,
контраст читаем, ничего не обрезано краем**.

## HUD-ряд — ИДЕНТИЧЕН styleframe-03 (обязательно на всех экранах с HUD)

Раскладка 1-в-1 со styleframe-03. Подписи (ДЕНЬГИ/ЗДОРОВЬЕ/ЭНЕРГИЯ/ОТНОШЕНИЯ) —
**под** элементами, тёмно-синие (`#1f3a96`). Толстые стикер-обводки.

- **Возраст:** синий квадрат-стикер `x46 y30 w200 h224`, белый кант 14; «ВОЗРАСТ»
  белым сверху + крупная цифра.
- **Деньги:** **СИНЯЯ пилюля** (кобальт `#2f54c8`) `x270 y30 w330 h88`, белый кант
  9; «₽ N» белым по центру; подпись «ДЕНЬГИ ◎ (×mult)» под пилюлей.
- **Здоровье:** белая капсула `x626 y30 w290 h72`, кант 6; иконка-сердце слева +
  красный бар; подпись «ЗДОРОВЬЕ» под капсулой.
- **Энергия:** белая капсула `x940 y30 w290 h72`; иконка-молния + жёлтый бар;
  подпись «ЭНЕРГИЯ».
- **Отношения:** белая капсула `x1254 y30 w380 h72`; зона-бар
  красный/жёлтый/**зелёный(HOLD ZONE)**/жёлтый/красный + бело-контурные
  стрелки-маркер (вверх/вниз) в позиции значения; подпись «ОТНОШЕНИЯ».
- **Кнопка-ребёнок:** центр `(1850,88) r44`, белая (погашена) / жёлтая свечение
  (вспышка), лицо по центру.
- **Кольцо таймера:** центр `x960`, `y150` (мин. HUD) или **`y250` (полный HUD —
  в ЗАЗОРЕ под HUD, НЕ поверх шкал)**, радиус 90; красная дуга = остаток.
- **Карточка-шатёр:** центр `x960`, кобальт, белый кант 18, радиус 46, золотые
  лампочки по периметру; текст авто-ужимается под ширину (перенос на 2 строки).
- **Плашки ответа:** ДА центр `(610,940) 420×190` (зелёная, тёмный текст),
  СПАСИБО НЕ НАДО `(1310,940) 470×190` (красная, белый текст); стрелки-
  треугольники `x352`/`x1602`; длинные подписи переносятся.
- **Мелкий шрифт карты:** тёмная плашка под карточкой (не на канте).
- **Контраст:** тёмный текст на зелёном/жёлтом/белом, белый на красном/кобальте.
  Никакого белого-на-жёлтом впритык и полупрозрачного текста.
